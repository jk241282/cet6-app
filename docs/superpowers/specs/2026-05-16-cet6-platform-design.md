# CET-6 备考学习平台 — 设计文档

## 概述

一个面向大学生的 CET-6 英语六级考试备考平台，提供词汇背诵、阅读理解、翻译训练、写作训练、听力训练和模拟考试六大学习模块。所有学习内容来源于历年真题和考纲资料，覆盖面广、内容详细。

## 技术架构

- **前端**: Vite + React 19 + TypeScript + Tailwind CSS 4
- **后端**: Node.js + Express + TypeScript
- **数据库**: SQLite (better-sqlite3)
- **状态管理**: Zustand
- **路由**: React Router v6
- **鉴权**: JWT (7天过期)
- **项目结构**: 单项目目录，Vite 开发代理到 Express，生产构建 Express serve 静态文件

## 功能模块

### 1. 用户系统
- 注册（用户名 + 邮箱 + 密码）
- 登录 / 退出登录
- JWT token 鉴权
- 个人学习统计与进度

### 2. 词汇背诵（核心模块）
- 6000+ CET-6 词汇，全部附带详细知识点
- 智能抽词：从未掌握词池中随机抽取，每个词展示：
  - 单词 + 英美音标
  - 核心释义 + 全部词义（按常用度排列）
  - 真题例句（含年份、来源板块）+ 中文翻译
  - 短语搭配 + 例句
  - 近义词 / 反义词（含语境差异说明）
  - 词根词缀 + 记忆技巧
- 三种用户反馈：已掌握（移出词池）/ 不熟（保留）/ 太难（暂跳）
- 艾宾浩斯间隔复习：已掌握词汇定期复习
- 背词进度统计

### 3. 阅读理解
- 历年真题阅读文章，按话题分类（科技、环境、教育、社会等）
- 选择题 + 填空题型
- 答案解析 + 原文定位
- 生词一键加入词汇本

### 4. 翻译训练
- 汉译英题目（历年真题 + 模拟题）
- 参考译文 + 关键采分点标注
- 用户输入对比参考译文，差异高亮
- 翻译技巧提示

### 5. 写作训练
- 写作题库（按题型分类：议论文、书信、图表、应用文）
- 写作模板库：每种题型提供段落模板和常用句型
- 写作佳句库：按话题/功能分类，可浏览背诵
- 范文展示 + 大纲分析
- 用户写作区域 + 自评工具

### 6. 听力训练
- 历年真题听力音频
- 题目展示 + 听力原文
- 答案与解析
- 支持 AB 复读（可选）

### 7. 模拟考试
- 按真实 CET-6 结构组卷
- 计时功能
- 自动评分（客观题）
- 成绩记录 + 历史对比
- 错题本：所有模块错题自动收集

## 数据库设计

### 核心表
- `users` — 用户账户
- `vocabulary` — 词汇主表（6000+ 词）
- `word_meanings` — 一词多义
- `word_examples` — 真题例句
- `word_phrases` — 短语搭配
- `word_relations` — 近义/反义词
- `reading_passages` — 阅读文章
- `reading_questions` — 阅读题目
- `translation_exercises` — 翻译练习
- `writing_topics` — 写作题目
- `writing_templates` — 写作模板
- `writing_sentences` — 写作佳句
- `listening_episodes` — 听力内容
- `listening_questions` — 听力题目
- `exams` / `exam_results` — 模拟考试
- `user_vocabulary` — 用户背词进度
- `user_errors` — 错题本

### 词汇表核心字段
- 单词、英美音标、词性、难度等级、频率排名
- 词根、记忆技巧、是否超纲
- 多个词义、多条真题例句（含年份来源）、短语搭配、近反义词

## UI 设计

### 导航布局
- 左侧 200px 固定导航栏（深色背景）
- 内容区独立滚动
- 导航项：仪表盘 | 词汇 | 阅读 | 翻译 | 写作 | 听力 | 模考

### 配色方案：靛紫渐变
- 主色：indigo-600 (#4f46e5) / purple-600 (#7c3aed)
- 侧栏背景：slate-900 (#0f172a)
- 已掌握：emerald-500 (#10b981)
- 需复习：red-500 (#ef4444)
- 新词汇：amber-500 (#f59e0b)
- 背景：slate-50 (#f8fafc)

### 词汇卡片设计
- 顶部靛紫渐变头部：大字单词 + 音标 + 核心词性释义
- 下方分区展示：真题例句、短语搭配、近反义词、记忆技巧
- 底部操作按钮：已掌握（绿）/ 不熟（红）/ 太难（灰）

### 字体
- 中文：系统默认中文字体（微软雅黑 / PingFang SC）
- 英文：Inter / system-ui

## API 设计要点

- RESTful 风格，`/api/` 前缀
- JWT Bearer token 鉴权
- 分页查询（词汇列表、阅读题列表等）
- 词汇抽取接口：`POST /api/vocabulary/draw`（从未掌握词池随机抽取 N 个）
- 词汇状态更新：`PATCH /api/vocabulary/:wordId/status`
- 模考评分：`POST /api/exam/:id/submit`

## 数据来源

通过网络搜索录入以下资料：
- CET-6 官方考纲词汇表
- 近 10 年 CET-6 真题（2015-2025）
- 各培训机构的词汇分析与记忆技巧
- 写作模板与佳句素材
